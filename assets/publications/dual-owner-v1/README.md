# Casper Dual — изображения владельца

Пять сцен дня и ночи полностью заменяют прежние варианты выбора Casper Dual. Каждая имеет Stories 1080×1920 и пост 1200×900 с отдельными редактируемыми текстовыми полями. Все пять доступны в существующих событиях блока A.

manifest.json содержит происхождение и SHA-256; overview.png показывает пары. Старые шаблоны удалены из активного каталога Dual; старые файлы сохранены только для неизменности уже сохранённых публикаций. Остальные лотереи не изменяются.
