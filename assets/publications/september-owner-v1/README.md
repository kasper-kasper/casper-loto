# 3 СЕНТЯБРЯ — осенние пейзажи владельца

Десять цельных атмосферных сцен: набережные, рябина, гавань, долина, фонари,
отражения, огонь и луна. Исходные имена и SHA-256 оригиналов — в manifest.json.
Направление владельца: полноценная иллюстрация с глубиной и настроением;
для будущих коллекций сохранять сценический подход и индивидуальную тему игры.

Stories 1080×1920 сохраняют портретный пейзаж; градиент защищает нижнюю область
редактируемого текста. Пост 1200×900 использует тот же пейзаж справа и тёплый
тёмный текстовый блок слева. Факты и результаты не вписаны в фон.
Кнопка Stories открывает игру с техническим кодом september.

Сборка: node scripts/build_september_publication_assets.cjs. Прежние 1046
записей сохранены; 320 новых редакторских вариантов используют 20 общих фонов.
В админке: Stories и посты → 3 СЕНТЯБРЯ → событие → Новая коллекция.
overview.png показывает все десять пар. Автоматические правила не подключены.

Владелец отдельно разрешил отправить один помеченный тестовый пост в @casper_loto;
это не разрешение включать постоянную или автоматическую отправку.
