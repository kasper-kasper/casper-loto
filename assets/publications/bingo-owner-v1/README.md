# Casper Bingo — коллекция владельца

Все десять предоставленных сцен заменяют прежнюю библиотеку выбора Casper Bingo. Каждая имеет Story 1080×1920 и пост 1200×900 с независимыми текстовыми полями; все доступны для событий блока A, включая джекпот и серию без его срыва.

Исходные изображения нормализованы в WebP; происхождение и SHA-256 в manifest.json. overview.png показывает обе композиции. Старые runtime-файлы оставлены только для неизменности уже сохранённых снимков публикаций; старые шаблоны исключены из активного каталога Bingo.
