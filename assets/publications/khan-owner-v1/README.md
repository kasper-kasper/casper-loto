# «6 из 36»: коллекция владельца, блок A

Девять присланных иллюстраций сохранены как отдельная коллекция. Восемь сюжетов
используют шары, билет, орбиты, пьедесталы или сцену; один — лототрон.
Исходные имена и SHA-256 оригинальных PNG записаны в `manifest.json`.
WebP-файлы сохраняют всю портретную композицию; оригинальные PNG остаются у владельца.

Каждый дизайн имеет Stories 1080×1920 и пост 1200×900. В Stories текст занимает
свободную нижнюю часть, защищённую мягким затемнением. В посте текст слева,
та же иллюстрация справа: обрезается только нижнее свободное пространство,
главный сюжет не растягивается. Логотип и название добавляются отдельно при сборке.
На картинках нет выдуманных результатов, чисел на шарах или данных игроков.

`overview.png` — обзор девяти пар с демонстрационным текстом. Точные зоны пяти
редактируемых полей и кнопки определены в `scripts/build_khan_publication_assets.cjs`.
Текст хранится отдельно от фона и отображается общим рендерером Admin / Mini App.
Пост экспортируется из админки вместе с введённым текстом.

Сборка: `node scripts/build_khan_publication_assets.cjs`. Она сохраняет прежние
758 записей и добавляет 9 дизайнов для каждого из 32 уже существующих названий
событий «6 из 36»: 288 ссылок на 18 общих фонов, а не 288 отдельных картинок.
Полная сборка `scripts/build_publication_assets.cjs` также подключает эту коллекцию.
Для sharp используется `PUBLICATIONS_NODE_PACKAGES` либо установленный runtime.

В админке: **Stories и посты → 6 из 36 → событие → композиция «Новая коллекция · …»**.
Сначала сохранить черновик, затем вручную опубликовать в Mini App.
Автоматические правила, отправка в канал и блоки B/C/D не подключены.

## Задание для следующих коллекций

Лучший вход — изображения плюс короткое описание игры. Без изображений достаточно
палитры, настроения и перечня разных сюжетов. Описание задаёт направление,
изображения закрепляют конкретный вид. Не нужно придумывать реальные тиражи для
запроса визуальных шаблонов.

«Добавь для [лотерея] [N] новых дизайнов блока A. Сохрани старые. Используй
[референсы / палитру / настроение]. Сделай разные сюжеты: [список]. Не повторяй
один главный объект во всей коллекции. Для каждого подготовь Stories 9:16 и пост
4:3 с общей иллюстрацией, отдельными редактируемыми зонами текста и кнопкой Stories.
Не назначай автоматические условия и не публикуй примеры игрокам».

Например, для «3 СЕНТЯБРЯ» можно перечислить календарный лист, осеннюю набережную,
золотые листья, фонарь, отражение в воде и билет. Это предложение сюжетов для
будущего задания, не утверждённая новая коллекция и не автоматический сценарий.
