# Значки достижений — 20 октября 2026, локально

Владелец утвердил первый вариант «Контур с характером» из
`design/achievement-icon-directions-2026-10-20.html` и поручил выбрать цвета
редкостей. Изменён только интерфейс Mini App. Каталог, сохранённые получения,
условия, награды, финансовый учёт и серверная схема не изменяются.

## Единая палитра

| Редкость | Цвет | HEX |
|---|---|---|
| Обычные | Серебристо-сиреневый | `#c6bfd8` |
| Необычные | Мятно-зелёный | `#8ed8b0` |
| Редкие | Голубой | `#80c7f6` |
| Эпические | Фиолетовый | `#c99aff` |
| Легендарные | Тёплое золото | `#f0c66e` |

Цвет задаётся один раз для редкости в `achievements.css` и наследуется значком,
числовой отметкой, подложкой и связанным оформлением. Обычные и эпические больше
не имеют почти одинакового оттенка. Неполученные значки приглушены независимо
от редкости. Текст категории и статус получения дополняют цветовую индикацию.

Секретность — независимый признак. До получения отображается только замок, без
конкретного рисунка, числовой отметки и индивидуальной формы. Полученный секретный
значок использует свой настоящий цвет редкости. Фильтр «Секретные» нейтральный;
это не дополнительная редкость.

## Реализация

- `achievementAppearance.ts`: оформление 22 известных ID, независимо от старого
  поля icon в неизменяемом снимке награды. Это позволяет обновить рисунки уже
  полученных достижений без изменения истории БД.
- `AchievementBadge.tsx`: один компонент для каталога, подробностей, последних
  получений в профиле и уведомлений. Поддерживает метаданные будущего каталога.
- `achievementGlyphs.ts`: только 26 нужных рисунков из той же версии Lucide
  1.17.0, которая использовалась в согласованном предложении. Сохранены ISC/MIT
  уведомления в `public/licenses/lucide.txt`. Полная библиотека и внешние запросы
  за значками в приложение не добавлены.
- `AchievementIcon.tsx`: отображение компактного набора и прежних совместимых
  пиктограмм для остальных элементов интерфейса.
- `Achievements.tsx`, `AchievementNotices.tsx`, `achievements.css`: подключение
  компонента и единой палитры во всех контекстах.

Новые достижения других категорий не создавались. Эти изменения в production не публиковались.
