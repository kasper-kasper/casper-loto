## Согласованные уточнения

- Casper Bell — подтверждённый ранее владельцем Casper Ball (`pss`), без повторного
  переименования или нового вопроса об идентичности игры.
- **CODE:** текущие правила `code_5_digits_economy_v2` содержат пять равноправных
  упорядоченных цифр и джекпот за пять совпадений. Отдельного серверного шифра
  в CODE нет (он есть в PULSE). Для «Почти взломал!» утверждены **ровно четыре
  совпавшие позиции из пяти**, название/авторское описание сохраняются. Условие
  «все 4 + не совпавший шифр» не реализовывать молча и игру ради него не менять.
- PULSE 2+2 считается независимо от совпадения шифра, как числовую
  комбинацию. Для «Два сердца» 1+2 — тоже при любом шифре. Это допускает выдачу
  редкого достижения вместе с будущим достижением за естественный джекпот.
- Для результатов «дважды»/«трижды» учитываются разные завершённые платные
  билеты; они могут находиться в одном тираже. Один билет, несколько его призов
  или повтор доставки события не образуют несколько выполнений.
- «Сороковка»: вся карточка закрыта, то есть максимальный сохранённый ход
  закрытия трёх строк ≤40. Механика и данные уже есть, правила Bingo не меняются.
- «Трижды повезло»: три соседних завершённых тиража одной лотереи; пропуск игроком
  промежуточного завершённого тиража разрывает серию. Мгновенные игры не тиражи.
- «Быстрый набор»: один московский день официальных тиражей, отдельные платные
  выигрыши в flash, shadow (CODE) и pulse; задержка обработки не сдвигает день.
- «Миллионер»: сумма фактических выплат по платным билетам. Подарочные выигрыши,
  CAS за достижения, бонусы и другие начисления исключены.
- Активность: common 3 разных дня, uncommon 7 подряд и 14 разных дней сохраняются.
  Новые rare — 21 подряд (максимальная достигнутая непрерывная серия) и 30 разных
  дней. Не подменять сумму дней серией или наоборот.

На этапе предложения код не менялся. После согласования выполнена локальная
реализация и необходимые проверки; сведения находятся в отчёте. Чтение профиля
не используется для пересчёта истории; инициализация новых показателей — отдельная
управляемая операция с исходной границы запуска системы.
