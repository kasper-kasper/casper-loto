# Эпические достижения — утверждённые награды, 20 октября 2026

Статус: реализовано **только локально** после утверждения владельцем. Последнее
указание повышает обычную вилку эпических выплат до **3–8 млн CAS**, исключение —
**20 млн CAS за 100 000 платных билетов**. Предыдущая таблица 2–15 млн заменена.

У 15 достижений предусмотрено по четыре будущих кейса. У «Большой коллекции» и
«Человека-оркестра» оставлен один: это объявленное перед реализацией распределение
в рамках пожелания «четыре почти везде, в самые интересные». Кейсы пока только
записаны в награде, выдача, инвентарь и открытие не реализуются.

«Без права на ошибку» повышено до десяти билетов Grand. «Большая коллекция»
сохраняет пять Grand, остальные пакеты — по десять. Grand — недельный тираж;
остальные подарки — ежедневные тиражные лотереи. Номинал каждого подарочного
билета оплачивает фонд через существующий ledger, комбинация случайная.

## Проверка условий по существующему локальному проекту

- Casper Bell — ранее подтверждённый владельцем Casper Ball (`pss`). В действующих
  правилах `casper_ball_5_36_1_8_economy_v2` комбинация 5+0 предусмотрена:
  фиксированный игровой приз 25 000 000 CAS. Для достижения учитывается ровно
  5 основных и ноль дополнительных совпадений, фактическая положительная выплата
  по платному билету. Экономика игры не изменяется.
- Grand: в `grand_fixed_5_35_2_5_economy_v2` предусмотрены 5+0 и 5+1 с игровыми
  призами 30 000 000 и 60 000 000 CAS соответственно. Для «Почти король» подходит
  любой из этих двух результатов. 5+2 не подменяет это условие.
- В локальном каталоге активны 11 действующих тиражных ID:
  dual, bingo, weekly, pll, pss, khan, september, grob, flash, shadow, pulse.
  `INSTANT_GAMES` содержит ещё три уникальные игры: kasper-live (LIVE), aurora,
  vault. Всего ровно **14 уникальных лотерей**. Поэтому «Мастер четырнадцати»
  выполним при включении всех трёх мгновенных игр; считать реальные разные ID и
  положительные призовые выплаты по платным билетам. Старую выключенную `daily`,
  версии правил, тиражи или фазы Dual не считать отдельными играми. Порог 14
  не снижается. Это проверка локального каталога; production не проверялся.
- CODE — как уже согласовано для редкой категории: пять равноправных цифр,
  отдельного джекпотного шифра нет. «Тройной взлом» учитывается за три разных
  завершённых платных билета с **ровно 4 позициями из 5**. Правила игры не менять.
- PULSE 2+2 — при любом результате шифра, как в редкой категории; нужны два
  разных платных билета. Для повторов FLASH/CODE/Ball и других результатов
  действуют разные билеты, включая билеты одного тиража; повторы обработки и
  призовые составляющие одного билета не размножают выполнение.
- «Две стороны медали» учитывается за **три результата суммарно** из множества
  {1+2, 2+1}, в любой смеси, а не за три одинаковых результата или по три каждого.
- «Большая коллекция» — десять разных выигрышных платных билетов, сумма каждой
  выплаты ≥10× её цены. Не суммировать малые выигрыши для получения одного 10×.
- «Без права на ошибку» — пять соседних завершённых тиражей одной лотереи;
  завершённый тираж без выигрыша игрока разрывает серию. «Человек-оркестр» — пять
  разных выигрышных лотерей за один день, включая мгновенные; день тиражных
  результатов официальный по Москве, мгновенных — день расчёта.
- Активность сохраняется: common 3 разных дня; uncommon 7 подряд/14 разных;
  rare 21 подряд/30 разных; epic 50 подряд/100 разных. Платные покупки, выплаты
  и прочий прогресс — с исходного запуска системы, без нового обнуления.
