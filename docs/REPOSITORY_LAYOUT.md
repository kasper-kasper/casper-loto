# Карта папок проекта

Порядок наведён локально 20 октября 2026. В корне остаются исходники,
инфраструктура, единая папка документации и единый архив.

| Где | Для чего | Загружать в GitHub |
|---|---|---|
| `backend`, `bot`, `frontend/{miniapp,admin,shared}` | Рабочее приложение | Да |
| `scripts`, `infrastructure`, `.github` | Команды, инфраструктура, CI | Да |
| `docs` | Инструкции, решения, отчёты; достижения в `docs/achievements` | После просмотра приватных сведений |
| `design`, `assets` | Визуальные решения и планы | По необходимости, с учётом прав на материалы |
| `archive/reference` | Исторические исходники и старые макеты | Только legacy-web и небольшие исследования; публикации исключены |
| `archive/local` | Проверки, скриншоты, логи, дампы, резервные ZIP | Нет |
| `.env` | Настоящие токены и пароли | Нет |
| `.env.example` | Шаблон без секретов | Да |
| `.venv`, `node_modules`, `.tools` | Зависимости, инструменты, локальный запуск | Нет |
| `backups`, `.maintenance` | Резервные копии, эксплуатационное состояние | Нет |
| `frontend/*/dist`, кэши | Результаты сборки | Нет |

`README.md`, `AGENTS.md`, `DEVLOG.md`, `CHANGELOG.md` оставлены в корне намеренно:
это стандартные документы; журналы также читаются сборкой backend.
Перемещать конфигурацию, окружение и зависимости ради внешней аккуратности
не требуется — это может сломать запуск.

История Git (`.git`) не переписывалась и не очищалась. Архивирование файла
меняет его текущий путь, но не стирает прежние версии из истории.

Новые отчёты сохранять в подходящий раздел `docs`, временные результаты —
в игнорируемую `archive/local/2026-10-20/temporary-work` или `.tools`, устаревшие материалы — в `archive`.
