# Casper Loto 1.71.1

PATCH prepared on 26 October 2026: compact achievement notifications and suppression
while the achievement catalog is visible.

| Component | Version |
| --- | --- |
| Public product | 1.71.1 |
| Mini App | 1.71.1 |
| API and bot | 1.60.0 (unchanged) |
| Admin | 1.61.2 (unchanged) |

The popup retains its clickable icon/title, compact CAS and ticket quantity, and a
separate dismiss button. Both redundant text rows are removed. Normal achievement
cards and full reward details remain unchanged.

Opening the catalog suppresses the current popup and its queue immediately.
Already queued and subsequently fetched notices are acknowledged silently using
the existing endpoint, at most ten IDs per request. The existing event-triggered
fetches and acknowledgement retries remain; no continuous polling, history scan,
new backend endpoint, schema migration or reward operation is introduced.
Acknowledged notifications stay in inbox history. New achievements earned after
leaving the catalog can display normally.

Verification is limited to the two affected achievement UI test files, Mini App
lint/typecheck/build and a mobile browser smoke. Publication uses the current
production baseline, VPS backups and the shared operations lock; only gateway is
rebuilt/restarted, with existing Admin artifacts retained. No full backend suite
or production test purchase is needed. Results are recorded after publication.

## Production result — 26 October 2026

Published from source commit `9f43c81b`. All 18 targeted achievement UI tests,
lint/typecheck and the clean locked-dependency Mini App build passed. Mobile smoke
at 320 and 390 px measured a 59.6 px popup without horizontal overflow. It verified
the clickable card, target detail opening and silent handling of queued/late notices.

VPS database/source backups and rollback image were preserved under the shared
operations lock. Only gateway was rebuilt/restarted; API/bot remained running.
HTTPS, exact client hashes, authentication boundaries, backup catalog and API health
passed. Six deployed source hashes matched; public product/Mini App are 1.71.1
and independent monitoring has zero warnings. No backend suite, schema migration,
production test purchase or manual Telegram message was performed for this patch.
