# Kasper Grand 5/35 + 2/5

Kasper Grand — главная еженедельная лотерея Casper Loto. Розыгрыш проходит по
воскресеньям в 20:00 МСК, продажи закрываются за пять минут.

## Комбинация

- поле №1: ровно 5 разных основных чисел от 1 до 35;
- поле №2: ровно 2 разных специальных числа от 1 до 5;
- поля выбираются и разыгрываются независимо;
- вероятность полного совпадения 5+2 равна 1 к 3 246 320;
- одинаковые комбинации в разных билетах разрешены.

В базе билет хранится одним неизменяемым массивом: основные числа используют
значения 1–35, специальные кодируются значениями 36–40 (смещение +35). API
передаёт метаданные двух полей, поэтому Mini App показывает специальные числа
пользователю как 1–5. Это сохраняет общую архитектуру билетов и тиражей без
отдельных таблиц и без неоднозначности между полями.

## Покупка и фонды

Покупка нескольких билетов и покупка на 1/5 тиражей выполняются одной
транзакцией. Нумерация билетов и тиражей остаётся общей для сущности `weekly` и
не сбрасывается при переходе на новый формат. 100% цены билета зачисляется в
джекпот через immutable ledger.

## Призовые категории

База для обычных категорий — только накопительная часть джекпота на начало
тиража: `max(jackpot - base_jackpot, 0)`. Каждый процент образует отдельный
категорийный пул и делится поровну между всеми билетами этой категории:

| Совпадение | Призовой пул |
|---|---:|
| 5+2 | весь джекпот |
| 5+1 | 20% накопительной части |
| 5+0 | 10% накопительной части |
| 4+2 | 8% накопительной части |
| 4+1 | 4% накопительной части |
| 3+2 | 2% накопительной части |

Если в категории нет победителей, её расчётный пул не выплачивается. Обычные
категории оплачивает Фонд Каспера: это сохраняет объявленный джекпот для будущих
тиражей. При 5+2 весь джекпот делится между победившими билетами, после чего
восстанавливается до зафиксированного для тиража базового значения из Фонда
Каспера. Все суммы — целые CAS; остаток деления распределяется детерминированно
по возрастанию номера билета.

Результат генерируется `secrets.SystemRandom`: сначала независимо 5 из 35,
затем 2 из 5. Settlement идемпотентен, завершённый тираж неизменяем, пустой
тираж также получает результат.

## Переход со старого формата

Завершённые тиражи 5/20 и их билеты остаются неизменной историей. Активные
билеты старого формата переводятся в статус `REFUNDED`, их полная стоимость
возвращается игрокам из джекпота отдельными ledger-записями. Следующий
запланированный тираж сохраняет свой номер, но получает правила Kasper Grand.
