# Отключение публикаций и очистка VPS — 19 октября 2026

Владелец явно разрешил локальный архив и последующее удаление с сервера
публикаций в канал, всех связанных сторис/ленты и изображений. Сообщения
в самом Telegram не удаляются. Игровые розыгрыши и финансовая история сохраняются.

## Архив

Локальная папка: `backups/channel-publications-2026-10-19/` (исключена из Git).
В ней отдельные дампы редакционных таблиц, CSV редакционного аудита, материалы,
прежние серверные резервные копии и Docker-образы приложения. Контрольные суммы,
проверка содержимого tar и перечень объектов фиксируются до удаления.

Первый экспорт: 17 374 публикации, 149 редакционных состояний,
1 830 интересных фактов, 32 партии фактов, 1 объявление распределительного тиража,
17 382 записи редакционного аудита. Файловый экспорт: 6 642 файла,
437 173 385 байт без сжатия. Перед остановкой/очисткой выполняется финальный экспорт.

## Изменения

- `EDITORIAL_ENABLED=false` по умолчанию и явно в production compose API/bot.
- Сбор, доставка и очистка редакционных предложений не открывают БД при отключении.
- Редакционные HTTP-маршруты возвращают 410; сторис и редакционное меню убраны.
- Назначение распределительных тиражей не зависит от канала и не создаёт пост.
- Изображения публикаций исключены из чистых клиентских сборок, release manifest
  и backend Dockerfile. Локальные исходники материалов сохраняются для архива.
- Удаление данных — отдельная явно авторизованная maintenance-операция после
  проверенного внешнего архива, при остановленных API/bot и под operations/backup
  locks. Только пять редакционных таблиц и аудит `entity_type='PUBLICATION'`.
- Триггер запрета изменения аудита временно отключается только внутри транзакции
  с эксклюзивной блокировкой этой таблицы и включается до commit. Проверяются
  неизменные количества билетов, тиражей, ledger и остальных записей аудита.
  Защита ledger/билетов/тиражей не отключается.
- Файлы удаляются по точному пути и совпадающему SHA-256 локальной копии.
  Старые образы удаляются только после переключения и проверки новой версии.

## Проверки и ограничения

Выпуск изолирован от локальной системы достижений: её миграция 0059, API,
воркер и изменения профиля не публикуются. Финансовые проверки выполняются
на временной базе. Отдельный PostgreSQL smoke проверяет удаление только
редакционного аудита и сохранение запрета удаления игрового аудита.

Очистка означает удаление из рабочей БД, файлов, резервных копий и образов
под управлением проекта. Побайтовое стирание дисков VPS, внутренних WAL-страниц
и снимков провайдера не обещается: выборочно подтвердить это из приложения нельзя.

## Завершено на production

API **1.57.1**, Mini App **1.67.1**, Admin **1.61.1** опубликованы.
Схема осталась `0058_dual_economy_versions`; таблиц достижений на VPS нет.
В каждой из пяти редакционных таблиц — 0 строк; аудита PUBLICATION — 0.
Сохранено 6 237 остальных записей аудита; триггер неизменяемости включён (`O`).
В транзакции очистки количества билетов, тиражей, ledger и игрового аудита
проверены до/после и совпали. Текущие точные количества после возобновления
работы: 738 387 билетов, 375 553 ledger-записи, 22 479 тиражей; обычная игра
может увеличивать эти числа.

Изображения отсутствуют во всех шести проверенных папках хоста и во всех
четырёх соответствующих путях работающих API/bot/gateway. Все семь архивированных
прежних образов отсутствуют; удалено 39 записей образов/промежуточных слоёв.
Дополнительно удалены ровно два старых BuildKit cache ID с публикационными
картинками/зависимым слоем. Общий Docker pruning и удаление volumes не выполнялись.
Для точного ограничения использован [фильтр id Docker Engine](https://docs.docker.com/reference/api/engine/version/v1.51/#tag/Build/operation/BuildPrune).
На VPS оставлена новая проверенная резервная копия очищенной БД:
`k-loto-20261018T215005Z.dump`. Старые копии вынесены локально.

Отдельный этап обслуживания удалил 447 архивированных файлов,
3,073,079,739 байт; большая часть исходных изображений уже была
удалена при продвижении проверенного release manifest. Эти числа нельзя складывать
с размерами всех Docker-образов: у образов есть общие слои.
Локальный архив сейчас занимает около 5.80 ГБ.
