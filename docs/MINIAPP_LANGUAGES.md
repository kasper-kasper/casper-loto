# Языки Casper Loto Mini App

Mini App 1.70.0 поддерживает русский и английский интерфейсы.

При каждом открытии язык определяется в таком порядке:

1. Явный выбор игрока в разделе «Личный кабинет → Язык приложения».
2. `Telegram.WebApp.initDataUnsafe.user.language_code`; при отсутствии объекта
   пользователя используется поле `user` из `initData` только для отображения.
3. Основной язык `navigator.languages`, затем `navigator.language`.

Региональные варианты (`en-US`, `en-GB`, `ru-RU`) распознаются. Для остальных
языков используется английский. Автоматически определённый язык не записывается
как выбор игрока. Проверка подписи и авторизация по-прежнему выполняются сервером.

Выбор хранится на устройстве в `localStorage` отдельно для Telegram ID; браузерное
превью имеет отдельный ключ. При очистке хранилища вновь действует автоматическое
определение. Серверной синхронизации между устройствами нет. Недоступное хранилище
не мешает переключению в текущей сессии. Событие `storage` синхронизирует окна одного
аккаунта на одном устройстве.

Переключение обновляет существующие React-компоненты без перезагрузки страницы,
сброса корзины, повторного запроса покупки или перемонтирования текущего экрана.
Тексты интерфейса, инструкции, правила, билеты, эфир, архив, достижения, коллекция,
стандартные уведомления и ошибки используют общий словарь
`frontend/miniapp/src/locales/en.json`. Русский исходный текст служит ключом.
Параметры сообщений подставляются отдельно от перевода; имена игроков не переводятся.
Авторские публикации отображаются в том виде, в котором они созданы.

Числа и даты используют `ru-RU` / `en-GB`. CAS остаются целыми числами;
английская версия использует запятую для группировки и точку для десятичных долей
сокращённых сумм. `MSK` обозначает прежний часовой пояс `Europe/Moscow`.
Идентификаторы, суммы, расписания, финансовые правила и сохранённая история не меняются.

Проверки: тесты разрешения языка, хранения, отказа хранилища, смены аккаунта,
обновления другого окна, сохранения React-состояния, полного покрытия статических
сообщений и параметров, точных CAS и московского времени; интеграционный RU → EN → RU
с настоящими профилем, каталогом и выбором чисел. Перед публикацией выполняется
чистая сборка Mini App с typecheck, lint и всем набором frontend-тестов.
Браузерный smoke использует только временное дизайн-превью и не делает покупок.

Релиз frontend-only: изолированный снимок текущего production с перечисленными
изменениями, локальная проверенная резервная копия, штатная публикация только
`gateway` под `/run/lock/k-loto-operations.lock`, backup, HTTPS/hash/auth/health
проверки. API, bot и схема БД не требуют пересоздания.

251 тест в 35 файлах прошли. Ожидание асинхронной записи корзины в существующем
межоконном тесте уточнено; производственное поведение корзины не менялось.

выбор и результат на 320×568. Горизонтального переполнения нет, результат помещается
без внутренней прокрутки. Временные визуальные фикстуры и сервер превью удалены/остановлены.

Исходники остальных сервисов, shared и админки сохранены побайтно; проверена прежняя
сборка Admin. Перед публикацией под общей блокировкой подтверждено совпадение

`archive/local/2026-10-22/miniapp-en-release/`. На VPS выполнены backup БД,
