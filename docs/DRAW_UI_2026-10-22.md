# Тиражные экраны: мобильная компоновка и инструменты покупки

Mini App 1.69.1, frontend-only. Владелец разрешил сразу опубликовать исправления.

Новогодняя игра: компактный заголовок, четыре ряда предметов рассчитываются от доступной высоты Telegram с учётом safe area сверху/снизу. На 320×568, 390×700/844 и 430×932 последний ряд и полоска выбранных символов располагаются выше фиксированной покупки. Огоньки нижнего края перенесены к полоске билета; они используют прежний бюджет видимости и reduced motion.

Вернулись общие инструменты ×1/×5/×25, участие в одном/пяти тиражах, сохранение/выбор/удаление любимых троек. Миниатюры избранного показывают предметы. Используются прежние серверные API и ограничения; финансовые правила не менялись.

Проверка охвата: общий TicketComposer обслуживает Grand, 2:22, Ball, 6 из 36, Mini, 3 СЕНТЯБРЯ, Halloween, Dual и новогоднюю игру. Быстрые покупки есть у всех. Для Dual сервер допускает один билет на пару раундов, поэтому повтор на пять тиражей скрыт; существующее серверное избранное теперь доступно отдельным раскрывающимся блоком с подписями NIGHT/DAWN. Bingo использует готовые карточки: ×1/×5/×25 уже есть, избранные числа задают поиск карточек, покупка покрывает один тираж. Fast и мгновенные игры не изменены.

Новогодняя карточка занимает отдельную полную строку каталога. По уточнению владельца изображение заполняет всю карточку; надписи лежат на плавном затемнении, без вертикального разделения. Метка «Праздничная» сохранена, у Mini — «Классика». Обычные карточки больше не растягиваются до высоты сезонной.

Проверки: 47 профильных frontend-тестов (NewYear, TicketComposer, MiniTicket, BingoView, performance), затем 11 NewYear после исправления типов теста и профильные проверки Dual/App после включения избранного; typecheck/lint и чистая production-сборка. Временная визуальная фикстура проверяет мобильные размеры с Telegram insets 92/34px, действия избранного/повтора без реальных покупок; после проверки удаляется. Публикуется только gateway с backup и независимым health/HTTPS/hash контролем.
