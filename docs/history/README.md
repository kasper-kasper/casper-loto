# Earlier project history

**English** · [Русский](README.ru.md) · [Changelog](../../CHANGELOG.md) · [Devlog](../../DEVLOG.md)

This overview groups small related changes into milestones. It is an editorial
summary, not a new release numbering scheme. The dates below identify periods
in the original records; they do not assert that every recorded experiment
was deployed. Retired features are part of the history, not current promises.

| Recorded period | Work grouped together |
| --- | --- |
| 18–23 October 2026 | Economy update, retirement of channel publishing, achievements, Mini and New Year games, English interface, private GitHub preparation. See the [current Changelog](../../CHANGELOG.md). |
| 11–17 October 2026 | Recovery of interrupted purchases, ticket-history pagination, profile and live-data performance, integrity checks, monitoring and backup repairs. |
| 9 October 2026 | Illustrated catalogue, Halloween presentation, Grand's dedicated scene, Aurora and Vault instant games, distribution-draw administration and mobile refinements. |
| 4–8 October 2026 | Fast and LIVE presentation, draw archive, Dual ticket refinements, and the former Stories/channel publication tools and artwork. Those publication tools were retired later in October. |
| 24–28 September 2026 | Dual's mobile ticket, bounded automatic participation, faster startup, redesigned home/profile/catalogue, and the Bingo and classic number-ticket presentation. |
| 21–23 September 2026 | Fast rule variants, LIVE instant tickets, combined ticket history, purchase controls, player dossiers and jackpot search. Includes experiments in the former standalone web client. |
| 14–15 September 2026 | Bingo mechanics and selection, Fast purchases, continuous ticket buying, quieter notifications, live draw presentation and owner tools. |
| 4–5 September 2026 | Classic 6 of 36, Grand and Fast development, profile and archive, themed games, catalogue/navigation, number selection and mobile refinements. |

journals. Detailed new verification reports belong in `docs/`; temporary evidence
and local data remain in ignored folders. Git history has not been rewritten.
