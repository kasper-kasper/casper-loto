# Прежняя история проекта

[English](README.md) · **Русский** · [Changelog](../../CHANGELOG.ru.md) · [Devlog](../../DEVLOG.ru.md)

В обзоре связанные мелкие изменения собраны по этапам. Это редакционная сводка,
а не новая нумерация выпусков. Даты обозначают периоды исходных записей
и не означают, что каждый эксперимент был опубликован. Завершённые возможности
описываются как история, а не как обещание действующего функционала.

Оба снимка побайтово сохраняют журналы до редакционной переработки 23 октября.
В них остаются отдельные мелкие исправления, смешение русского и английского,
локальные работы, повторяющиеся номера компонентов, нестандартные заголовки
и старый порядок записей. Некоторые прежние заголовки были пустыми;
соседний текст сохранён без изменений. Указатель включает нестандартные
заголовки, которые пропускал прежний обработчик журналов в админке.

Снимки являются архивом. Новые публичные записи добавляются в корневые журналы.
Подробные новые отчёты о проверках — в `docs/`; временные результаты
и локальные данные остаются в игнорируемых папках. История Git не переписана.
