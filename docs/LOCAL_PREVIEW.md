# Casper Loto на ноутбуке

На рабочем столе создан ярлык **Casper Loto — локально**.

1. Откройте ярлык двойным щелчком.
2. Дождитесь надписи «ГОТОВО». Откроется браузер с адресом
   <http://127.0.0.1:5173>.
3. Смотрите обновления, покупайте тестовые билеты, откройте «Моё» → «Достижения».
4. Пока пользуетесь приложением, оставьте окно запуска открытым.
5. Для остановки закройте окно запуска или нажмите в нём Ctrl+C.

Если Docker ещё выключен, запуск автоматически откроет Docker Desktop.
Это может занять несколько минут. Повторный щелчок по ярлыку открывает уже
запущенную версию, не создавая второй сервер.

Используется отдельный тестовый аккаунт. Покупки, результаты и прогресс
сохраняются между запусками в локальном PostgreSQL. Утверждённые награды CAS и
подарочные билеты работают локально. Кейсы только указаны в составе наград.
Для проверки версии с наградами выбран отдельный тестовый профиль; прежний
профиль с неоценёнными достижениями сохранён без изменений. В тестовом аккаунте уже может быть прогресс после проверки
разработчиком. Кнопка «+ TEST CAS» добавляет только локальные тестовые CAS.

Интерфейс берётся из текущих файлов `frontend/miniapp` и обновляется при
сохранении изменений. После изменения серверного Python-кода закройте окно
запуска и откройте ярлык снова. Перенос папки проекта потребует обновить ярлык.

## Как устроен запуск

- `scripts/start_local_preview.cmd` запускает `scripts/local_preview.py`.
- API слушает только `127.0.0.1:8000`, Mini App — `127.0.0.1:5173`.
- PostgreSQL: контейнер `k-loto-achievements-local`, порт `127.0.0.1:55439`,
  отдельная база `k_loto_achievement_preview`.
- Создание новой базы использует миграции и начальную конфигурацию из уже
  утверждённых условий. Все корректировки тестовых фондов отражаются в ledger.
  Исторический переход экономики, возвраты и сбросы счётчиков не запускаются.
- Начальная настройка допускается только без пользователей, билетов и тиражей.
  Повторный запуск сохраняет историю и дату начала учёта достижений.
- Корневая `.env` не читается: Python работает из `.tools/local-preview`,
  а окружение дочерних процессов формируется из разрешённого списка.
- Реальные токены бота, учётные данные VPS и админки не передаются.
  Отправка Telegram, публикации и сводки владельцу отключены; бот не запускается.
- В `.tools/local-preview` находятся журналы и отдельный секрет тестовой сессии.
  Эта папка исключена из Git. Не создавайте в ней `.env`.
- При закрытии окна Windows Job Object завершает API и Vite. Docker и база
  остаются доступны другим локальным задачам. Docker можно закрыть отдельно,
  когда он больше не нужен; не удаляйте контейнер/том с тестовыми данными.
- Если порты заняты другой программой, запуск останавливается с ошибкой.
  Подробности: `.tools/local-preview/setup.log`, `api.log`, `miniapp.log`.

Рабочий VPS при таком запуске не используется. Браузерный просмотр позволяет
проверять приложение, но особенности встроенного окна Telegram на телефоне
проверяются отдельно.
