# Как менять тексты Mini App

Основные пользовательские подписи собраны в одном файле:
`frontend/miniapp/src/content.ts`.

Откройте файл в VS Code и следуйте инструкции в самом начале файла. Тексты
разделены на «ШАПКА», «ГЛАВНАЯ», «МОЁ», «УВЕДОМЛЕНИЯ», «ЭФИР», «НАВИГАЦИЯ» и
«КНОПКИ». Меняйте только содержимое кавычек справа от двоеточия.

Для проверки и публикации откройте терминал VS Code в папке `k-loto` и
выполните одну команду:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/publish_miniapp_texts.ps1
```

Сценарий работает только при единственном изменённом файле `content.ts`: он
проверит Mini App, создаст Git commit, сделает backup и обновит gateway на VPS.
При наличии других изменений он безопасно остановится.

Названия лотерей, стоимость билета, джекпот и расписание являются данными, а не
текстами интерфейса. Их следует менять в Admin Panel только для будущих тиражей.
