# Как менять тексты Mini App

Основные пользовательские подписи собраны в одном файле:
`frontend/miniapp/src/content.ts`.

Откройте файл в VS Code и следуйте инструкции в самом начале файла. Меняйте
только текст внутри кавычек справа от двоеточия. После сохранения попросите
разработчика выпустить изменения — публикация требует сборки и проверки.

Названия лотерей, стоимость билета, джекпот и расписание являются данными, а не
текстами интерфейса. Их следует менять в Admin Panel только для будущих тиражей.
