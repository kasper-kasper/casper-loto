# Fast device artwork

Created 2026-09-28 with the built-in ImageGen tool, one generation per device, without reference images. Transparent PNG originals were resized with Pillow to 480×480 and encoded as RGBA WebP, quality 86/method 6.

Project assets:

- `frontend/miniapp/src/assets/lotteries/fast-flash-device-v1.webp` — 45,626 bytes.
- `frontend/miniapp/src/assets/lotteries/fast-pulse-device-v1.webp` — 55,786 bytes.
- `frontend/miniapp/src/assets/lotteries/fast-code-device-v1.webp` — 45,322 bytes.

These are 3D-render-style raster objects animated with CSS, not runtime 3D meshes. The number keys, counters, result slots and timing are independent DOM elements driven by existing state. Images have explicit dimensions, are confined to the lazy Fast screen, and ambient motion respects reduced motion, off-screen visibility and backgrounding. Legacy SHADOW uses the cipher object with a violet presentation; live result data is unchanged.

The bolt is compact and sculptural with visible side thickness. Blue light reflects onto the metal. No scattered sparks.
