# Блок A: решения владельца и редакторские материалы

Это подготовка автоматизации, не включённые правила отправки.
Новые условия не подключены к scheduler, Mini App или Telegram.

## Подтверждено владельцем

- A1 — автоматические публикации о джекпотах; Fast включён, с возможностью отключить.
- A2 — предложения с результатами в админке.
- A3 — победители джекпота внутри публикации A1; остальные предложения согласно согласованной схеме.
- A4 — автоматические публикации о продажах, участниках и активности после определения критериев.
- A5 — предложения по понедельникам, средам и пятницам при проверке в 12:22 МСК.
- A8 — ручные сообщения об изменениях игры.
- Для Fast и LIVE сводки поддерживаются; LIVE не получает несуществующие события тиражей/накопительного джекпота.
- Предложение содержит выбранную картинку и текст, предпросмотр, действия «Принять» / «Отклонить» и возможность правки. До принятия оно не видно игрокам и не отправлено в канал.
- Проверка новых событий три раза в день: 12:22, 18:35 и 22:22, Europe/Moscow. После каждого прохода автоматические публикации отправляются сразу. Все события одного тиража объединяются; разные тиражи публикуются отдельно без интервалов и дневного лимита. Проверка после каждого тиража не выбрана.
- Продажи только за один тираж: отметки 10 000 / 50 000 / 100 000 / 500 000 / 1 000 000 билетов включительно; ниже первого порога новостей нет. Накопительные продажи по игре (A4.5) не включаем.
- Джекпот: согласован подход с индивидуальными отметками по игре, например ×1,5 / ×2 / ×3 относительно утверждённой базы.
- Участники — уникальные люди, выигрышные билеты — отдельный счётчик, выплаты — фактические CAS. Рекорды игры сравниваются в действующем формате; статистика проекта отдельно.
- A4.3: новость о рекорде участников только при одновременном выполнении двух условий: не менее 500 уникальных участников за один тираж и превышение предыдущего рекорда минимум на 20%. Один человек с несколькими билетами считается одним участником.
- Имена, usernames и другие персональные сведения победителей никогда не публикуются.
- События одного тиража объединяются в одну публикацию; возможно несколько изображений/карточек.
- Автоматический выбор подходящего шаблона случайный: внутри игры и темы исключаем последние 3 картинки и последние 2 текста. Если вариантов мало, выбираем самый давно использованный. Ручной выбор сохраняется.
- Серия без джекпота: каждые 50 завершённых тиражей подряд; для Fast — каждые 200. Новость при пересечении каждой отметки, без повторного сообщения об одной отметке. Срыв джекпота обнуляет серию.
- После простоя события старше 48 часов становятся предложениями; успешно отправленное событие не отправляется повторно.
- Stories Mini App: срок 24 часа; посты Telegram сохраняются; непросмотренные сначала с яркой рамкой, просмотренные в конце с приглушённой рамкой.
- Нативные Telegram Stories не входят в задачу. Это подтверждённый формат, а не открытый вопрос.
- Несколько событий одного тиража — одна публикация, при необходимости с несколькими изображениями в посте и последовательными карточками в Mini App. Формат согласован; доставка таких групп ещё не реализована.
- Хештеги по последней реплике: согласована прежняя схема — видимые игра + тема; общие теги внизу под спойлером. Требование скрыть все теги было отменено владельцем в той же реплике.
- Картинки ещё дополняются. Тексты ниже предварительные, для последующей редакторской работы; постоянная отправка пока выключена.

## Файлы

- `copy-bank.v1.json`: по три варианта текста для каждой группы автоматических A1/A4, всего 30. Общие блоки отделены от вариантов; перед использованием подставляются только проверенные значения.
- `texts.v1.md`: те же 30 вариантов в читаемом виде, с отдельными текстами для Stories и Telegram. Фигурные скобки обозначают места для реальных данных.
- `story-preview.html`: интерактивный макет непросмотренных/просмотренных Stories. Это демонстрация поведения, не изменение production.

В текстах нельзя оставлять незаполненные параметры, добавлять выдуманные суммы,
обещания выигрыша или персональные сведения. Каталог текста не является источником
фактов или правил лотереи. Суммы и метрики предоставляет серверный сервис.
