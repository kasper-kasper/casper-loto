Каждая лотерея имеет собственную последовательную нумерацию тиражей и
билетов. Совпадение времени основной и Fast-лотереи допустимо: это независимые
тиражи, которые планировщик проводит идемпотентно.

## Fast

Fast работает непрерывным циклом без одновременных тиражей:

1. `FLASH` — начиная с 00:00, затем каждые 9 минут.
2. `CODE` — начиная с 00:03, затем каждые 9 минут.
3. `PULSE` — начиная с 00:06, затем каждые 9 минут.

Таким образом, новый Fast-тираж проходит каждые 3 минуты, а каждая конкретная
лотерея возвращается через 9 минут. Продажи закрываются за 8 секунд до старта.

### Точные минуты на все сутки

| Часы | FLASH | CODE | PULSE |
|---|---|---|---|
| 00, 03, 06, 09, 12, 15, 18, 21 | :00, :09, :18, :27, :36, :45, :54 | :03, :12, :21, :30, :39, :48, :57 | :06, :15, :24, :33, :42, :51 |
| 01, 04, 07, 10, 13, 16, 19, 22 | :03, :12, :21, :30, :39, :48, :57 | :06, :15, :24, :33, :42, :51 | :00, :09, :18, :27, :36, :45, :54 |
| 02, 05, 08, 11, 14, 17, 20, 23 | :06, :15, :24, :33, :42, :51 | :00, :09, :18, :27, :36, :45, :54 | :03, :12, :21, :30, :39, :48, :57 |

Пример одного цикла: `12:00 FLASH → 12:03 CODE → 12:06 PULSE →
12:09 FLASH`.

FLASH, CODE и PULSE являются независимыми лотереями: у каждой свои тиражи,
билеты, джекпот и история. За 20 секунд до старта соответствующая карточка в
разделе Fast превращается в короткий эфир. Числа появляются по серверной
временной шкале, результат остаётся на экране 12 секунд, затем возвращается
обычная карточка.

Планировщик заранее создаёт будущие тиражи, проводит пустые тиражи,
восстанавливает пропущенные после перезапуска и не допускает повторного
settlement.
