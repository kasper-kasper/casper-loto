# Пользовательская Web-версия

## «ГРОБ» — Phaser experience

Веб-версия «ГРОБ» загружается отдельным lazy chunk и работает как полноэкранная
Phaser 3 сцена. React сохраняет сессию, CSRF, API-запросы и серверные snapshots;
Phaser отвечает только за мир, ввод и анимации. На сцене находятся саркофаг-машина,
16 физических печатей, три гнезда билета, центральная красная печать покупки и отдельные устройства быстрых
покупок x1/x5/x25. Ручная покупка не закрывает сцену: после серверного ответа
появляется новый пустой билет. Неоднозначная попытка хранит исходный payload и
idempotency key в `sessionStorage`.

Эфир «ГРОБ» доступен исключительно в общей вкладке «Эфир»: внутри основной
игровой комнаты нет кнопки или локального переключателя трансляции. Пока вкладка
открыта, React запрашивает общий standard feed и отдельный
`lottery_code=grob`, чтобы не потерять одновременное окно «ГРОБ». Phaser раскрывает
числа исключительно по серверным `reveal_at` и берёт выигрыш из live DTO. Desktop
и portrait mobile используют разные постановки одной сцены; все 16 печатей
доступны без прокрутки. Telegram Mini App и серверная математика не изменены.

В 1.39 Fast получил три независимые игровые секции с новыми арт-сценами. На широком
экране — постоянные колонки FLASH / CODE / PULSE, на мобильном — вертикальные секции
и закреплённые ссылки. Случайный билет покупается одним нажатием с показанной ценой;
ручной выбор раскрывается на месте. Эфир каждой игры находится под её покупкой,
не требует перехода и следует серверным timestamp. Есть остановка анимации.
При неоднозначном сетевом сбое сохраняется прежний ключ покупки; после смены тиража
сначала требуется проверить билеты/баланс, затем явно разрешить новую покупку.

С версии 1.38 Web имеет самостоятельный адаптивный дизайн, включая телефоны:
тёмно-синие игровые сцены, золото фирменного знака и красный Casper Fast.
Адрес остаётся `<MINIAPP_URL>/web/`.

Для входа с тем же балансом и билетами, что в Telegram: отправить боту `/web`,
ввести одноразовый 16-символьный код на сайте (срок пять минут). В кабинете можно
добавить логин и пароль к этому же ID. Новая регистрация логином и паролем создаёт
новый профиль; существующему Telegram-игроку следует сначала войти через Telegram.
Почта не запрашивается. Автоматического слияния разных профилей нет.

Новые API: `POST /api/v1/web/auth/telegram` и защищённый CSRF
`POST /api/v1/web/auth/password`. Сессия возвращает `user_id`.

Ниже сохранено описание первоначальной desktop-версии; ограничение desktop-only
заменено адаптивным интерфейсом в 1.38.

Web-версия предназначена только для обычного настольного браузера. Она работает
на том же backend и с теми же лотереями, тиражами, билетами, балансами и ledger,
что Telegram Mini App, но не требует Telegram.

## Вход

Production-адрес: `<MINIAPP_URL>/web/`.

Новый игрок выбирает «Зарегистрироваться», задаёт логин и пароль (минимум восемь
символов) и сразу получает стандартный одноразовый приветственный баланс через
ledger. Повторный вход выполняется по тому же логину и паролю. Пароль хранится
только как Argon2-хеш, сессия — в подписанной Secure/HttpOnly cookie, а покупки
защищены CSRF-токеном.

## Возможности

- витрина всех активных лотерей в хронологическом порядке;
- обычные, составные и упорядоченные комбинации, multi-ticket и 5 тиражей;
- выбор готовых билетов Kasper Bingo;
- активные билеты и история с загрузкой по 100 записей;
- статистика игрока;
- обычный эфир и отдельный Fast-эфир по серверной временной шкале.

Frontend публикуется как статические файлы в `/web/`. На телефоны интерфейс
специально не адаптируется: мобильным клиентом остаётся Telegram Mini App.
