# Архив Casper Loto

Материалы сохранены для справки и восстановления, не удалены.
Эта папка не включается в сборку контейнера или VPS-релиз.

## reference — исторические исходники

- `legacy-web/` — снятый с production отдельный браузерный клиент и его документы.
- `retired-publications/` — прежние макеты канала/сторис, изображения, документы
  и одноразовые генераторы. Сохранена исходная вложенность там, где она нужна
  для относительных ссылок.
- `design-studies/` — старые варианты Grand/Halloween и пояснения. Рабочие
  изображения действующих игр остаются в клиентах.

Исходники legacy-web и небольшие дизайн-исследования могут храниться в Git.
Раздел `retired-publications/` исключён из Git целиком: старые изображения
и материалы канала сохраняются только локально. Это не включённые функции
и не актуальные эксплуатационные команды.

## local — приватный архив только на этом компьютере

`local/2026-10-20/` содержит прежнюю `.tmp`, снимки браузерных проверок,
логи, дампы локальных баз и архивы результатов из `.tools`.
Раздел исключён из Git: эксплуатационные материалы могут содержать
пользовательские данные и приватные настройки.

Перечни перемещений: `local/2026-10-20/moves.json` и
`local/2026-10-20/documentation-moves.json`. Для исходников и доступных
материалов проверены SHA-256 до и после перемещения. Установленные зависимости
перенесены с историческим клиентом без повторного хеширования.

Активный локальный запуск остаётся в `.tools/local-preview`, Node — в
`.tools/node`, рабочая Python-среда — в `.venv`. Резервные копии в `backups/`
и состояние `.maintenance/` оставлены на прежних местах.
